# Manifest, permissions and components

The Manifest tab shows `AndroidManifest.xml` decoded from Android binary XML. Values that point to resources keep their id, for example `@0x7f0e001b`.

The Permissions tab lists every permission the app asks for. Dangerous permissions, the ones a user must allow at run time, are marked.

The Components tab lists activities, services, receivers and providers. The Exported column says whether other apps can start them, and the Why column says where that comes from.
