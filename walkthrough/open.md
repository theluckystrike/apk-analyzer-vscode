# Open an APK

Click an `.apk` file in the Explorer. It opens in APK Analyzer instead of as unreadable text.

The Overview tab shows the package name, versionName and versionCode, the min, target and compile SDK levels, how many permissions and components the app has, its native ABIs, its DEX method totals and how it is signed.

For a file with another extension, right-click it and pick Open in APK Analyzer.
