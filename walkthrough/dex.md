# DEX method counts and APK size

A DEX file can reference at most 65,536 methods. The DEX tab shows how many each `classes.dex` uses, and the Packages tab shows the counts as a tree so you can see which library adds the most.

The Folders and Types tabs show where the bytes of the APK go, compressed and unpacked. On the Files tab, the hex link opens the unpacked bytes of any file.
